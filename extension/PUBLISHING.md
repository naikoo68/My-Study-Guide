# Publishing the Companion to the Chrome Web Store

Once the Companion is on the Chrome Web Store, installing it becomes a single
tap/click ("Add to Chrome") on **any** Chromium browser — including **Yandex
Browser for Android**, Brave, Edge and Chrome. No zip, no developer mode.

This guide gives you everything ready-made. The parts only you can do (they need
your Google account + a one-time fee) are clearly marked **[YOU]**.

---

## What's already prepared for you

- ✅ Icons at 16 / 48 / 128 px in `extension/icons/` and wired into `manifest.json`.
- ✅ A store-ready zip: **`frontend/public/companion-extension.zip`**
  (has `manifest.json` at the root, so you can upload it to the Web Store as-is).
- ✅ The listing text, permission justifications and privacy answers — below.

---

## Step-by-step

### 1. [YOU] Create a Chrome Web Store developer account
- Go to the **Chrome Web Store Developer Dashboard**:
  `https://chrome.google.com/webstore/devconsole`
- Sign in with the Google account you want to own the listing.
- Pay the **one-time US$5 registration fee** (Google charges this once, ever).

### 2. Get the upload zip
- Download **`companion-extension.zip`** — the same file your website's
  **Download Companion** button serves (or grab it from the repo at
  `frontend/public/companion-extension.zip`).
- Upload that zip directly in the dashboard → **"Add new item"**.

### 3. Fill in the store listing (copy-paste ready)

**Name**
```
My Study Guide Companion
```

**Summary** (max 132 chars)
```
Turn lecture text, captions and selected text on learning sites into quizzes, summaries and flashcards with your My Study Guide AI.
```

**Description**
```
My Study Guide Companion works alongside you while you study on YouTube,
Unacademy, Physics Wallah, Udemy, Coursera and other learning sites.

With one click it turns the study content you're already allowed to see —
lecture text, video captions and text you select — into:
  • practice questions and quizzes
  • concise summaries
  • flashcards
  • clear explanations

Everything is generated by your existing My Study Guide account's AI. The
Companion never asks for the password of any other website; it only reads the
page you are already viewing, and only when you ask it to.

You need a My Study Guide account with AI access to use the Companion. Sign in
once from the Companion popup and you're ready to go.
```

**Category:** Education
**Language:** English

### 4. [YOU] Privacy tab answers

- **Single purpose:**
  ```
  Convert study content the user is permitted to view into practice questions,
  quizzes, summaries and flashcards using the user's My Study Guide AI account.
  ```
- **Permission justifications:**
  - `activeTab` / `scripting` — read the text of the page the user is currently
    viewing, only when the user activates the Companion, to send it for AI
    processing.
  - `contextMenus` — add a right-click "Send to My Study Guide" option on
    selected text.
  - `storage` — store the user's My Study Guide sign-in token and the API/site
    URLs locally on their device.
  - Host permissions (`*.onrender.com`, `*.vercel.app`) — talk to the user's own
    My Study Guide backend and site.
- **Data usage:** The extension stores only the user's My Study Guide login
  token locally. It does not sell data or use it for anything beyond providing
  the feature. Page content is sent to the user's own My Study Guide backend for
  AI processing.
- **Privacy policy URL:** use your site's existing policy page, e.g.
  `https://mystudyguideme.vercel.app/privacy` (point to whatever your live
  privacy page is).

### 5. [YOU] Add screenshots
Google requires at least **one screenshot** (1280×800 or 640×400 PNG/JPG).
Easiest way: install the Companion on a computer (Load unpacked or from the zip),
open it on a YouTube lecture, and take a screenshot of the popup generating a
quiz. Add 1–3 of these.

### 6. [YOU] Submit for review
Click **Submit for review**. Google usually reviews within a few days. You'll get
an email when it's approved.

## After approval — flip the site button to "Add to Chrome"

Once you have the public store URL (looks like

the Connections page button from **Download Companion** to **Add to Chrome**,
pointing at that URL. Then it's a true one-tap install for everyone, phones
included.
